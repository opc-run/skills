# 超级智囊团 / opc-run-super-brainstorm

---

## 简介

一句话把问题丢给一群"人"，拿回来的不是一份答案，是**一场会议**。

普通 AI 问答是一个人自言自语；超级智囊团是自动挑出 3~5 位最对口的导师，让他们带着各自的人设、思维模型与技能工具箱依次发言，后面的人听着前面的人接话、反驳、点名下一位。

**核心价值**

- **观点会碰撞**：同一个问题你会拿到管理视角、投资视角、产品视角三套完全不同的推理链 —— 分歧本身才是最有价值的部分

- **导师不是同一个 AI 换头像**：每位导师的人设、代表作思维模型、决策准则都来自独立的知识页，发言风格与判据各不相同

- **讨论与结论分开**：Skill 给的是几位导师的观点交锋（分歧本身才是最有价值的部分）；
  最多 3 轮，说完就停，**不给结论**。
  **结论、继续追问、随时插话都在站内完整版** —— Skill 只开场，不给答案

- **随时取回**：每场讨论都有一个 `task_id`，随时能再取回来看；配上 API Key，讨论还能在站内打开继续追问导师

- **零依赖 + 本地缓存**：纯 Python 标准库，无需 pip install；已完成的讨论本地缓存，重复查看不消耗额度

**适用对象**

- 🧑‍💻 **独立开发者 / 超级个体** — 一个人做决策时，缺的不是信息，是几个不同视角的推演

- 🧭 **站在岔路口的人** — 要不要辞职、要不要招人、要不要换赛道

- 📊 **做战略 / 做取舍的人** — 想在拍板前把反对意见先听一遍

- 🤔 **卡住的人** — 自己想不明白，需要有人把问题拆开

## 功能特性

### 开一场讨论

- 提交一个问题，系统自动分析议题并挑出最对口的导师组局

- 支持 1~3 轮讨论（默认 2 轮），轮数越多交锋越充分，也越慢

- 讨论在服务端跑（3 位导师约 1~3 分钟，5 位更久），但**不用干等**：导师说完一条就出来一条，
  某位导师一说完你就能读到，不用等整场结束 —— 轮询前 30 秒每 5 秒一次、之后每 3 秒一次，**不消耗额度**

### 讨论结果

- 按轮次呈现每位导师的发言（含动作/表情、所属轮次、发言顺序），最多 3 轮

- **不给结论**：讨论停在各位导师各抒己见的地方。这个悬念是故意的 ——
  想看圆桌把分歧收敛成结论，去站内

- 结果可随时用 `task_id` 取回；进行中的讨论也能看到已产出的部分；
  已完成的讨论本地缓存 24 小时

### 成员名录

- 查看智囊团都有谁（称号 / 姓名 / 一句话简介），只读、不消耗额度

### 配了 API Key 之后

- **额度更高**：匿名每天 3 场（不扣点），配 Key 后按账号套餐；**每场 10 点**（与站内发起一场会议同价，讨论失败自动退）

- **讨论跟着账号走**：同一场讨论能在站内打开、继续追问导师、让圆桌出决议；
  匿名的话只能用 `task_id` 在当前这台机器上取回

### 站内完整版多出来的能力

| | Skill 版 | 站内完整版 |
| --- | --- | --- |
| 导师人数 | 3~5 位（看议题复杂度） | 5 位 |
| 讨论轮次 | 最多 3 轮 | 不限轮次（可一轮轮接着聊） |
| 给出结论 | ✗ | ✓ 一个明确的答案与下一步 |
| 用户介入 | ✗ | ✓ 随时插话，导师会追问你并等你答复 |
| 决议归档 | ✗ | ✓ 写入个人知识库 |

## 密钥获取与安全说明

- 未配置密钥也能用：**每天 3 场讨论**，不扣点

- 配置密钥后按所属套餐额度使用，额度高于匿名

- **每场消耗 10 点**（与站内「发起一场会议」同价）。只在配置了密钥时扣 —— 匿名不扣。
  讨论失败（导师推荐失败 / 超时）会**自动退回**，没产出就不收钱

- 配置密钥还有一个更重要的收益：**讨论跟着你的账号走**，登录后在站内能打开同一场讨论继续追问导师

- API Key 由 [OPC.run](https://opc.run) 提供，请前往 [注册页](https://opc.run/app/passport?from=skill&return_url=%2Fapp%2Fsession%2Flist) 注册账号，登录后从左侧菜单「API Keys」进入 [领取页](https://opc.run/app/profile/api-keys)

- 配置方式（任选其一；Windows 上若无 `python3` 命令，把示例中的 `python3` 换成 `python`）：

  ```bash

  python3 scripts/brainstorm.py auth sk_xxxx...   # 推荐：校验并保存到本地（POSIX 下设为 600 权限），--status 查看 / --clear 删除

  export OPCRUN_API_KEY="sk_xxxx..."              # 环境变量（优先级高于本地文件）

  {"env":{"OPCRUN_API_KEY":"sk_xxxx..."}}         # Agent 配置文件的 env 段

  ```

- 在提供密钥前，请确认其来源、可用范围、有效期及是否支持重置 / 撤销

- 禁止在代码、提示词、日志或输出文件中硬编码 / 明文暴露密钥

## 使用指南

直接用自然语言提问题即可，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| --- | --- | --- |
| 拿主意 | "我一个人做跨境电商，月流水 3 万，该不该招人" | 开一场讨论，返回几位导师的观点交锋（决议在站内） |
| 二选一 | "继续打工还是出来做独立产品" | 多视角推演，看清分歧在哪 |
| 评估风险 | "现在all in AI 应用方向，风险有多大" | 风险视角 + 机会成本视角交叉 |
| 看结果 | "刚才那场讨论再发我一次" | 用 task_id 取回（不消耗额度） |
| 看成员 | "你们智囊团都有谁" | 成员名录（只读） |
| 看额度 | "我还能问几场" | 配额查询（不消耗额度） |

## 使用场景

| 场景 | 角色 | 示例问法 | 收益 |
| --- | --- | --- | --- |
| 战略取舍 | 独立开发者 | "做工具还是做内容，先押哪个" | 拿到两套判据，看清分歧在哪 |
