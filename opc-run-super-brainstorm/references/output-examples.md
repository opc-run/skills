# 输出样例

脚本默认输出 Markdown。下面几份样例是**真实形状**，写答案时照着这个结构组织。

> ★ `ask` 是**增量输出**：下面这段内容不是最后一次性出现的，而是随着讨论推进
> 逐段打到 stdout 的（头部 → 第 1 位 → 第 2 位 → … → 引导尾部）。
>
> ★ **不给结论**：Skill 停在各位导师各抒己见的地方，结论是站内完整版的内容。
> 下面这份样例里**有一位导师向你提问了**（发言下的 `> ❓` 标记）——
> 这时脚本会把"有 N 位导师问了你问题"放在尾部最前面。


> ★ JSON 里**没有 `resolution` 字段** —— 接口层就不返回决议（Skill 只给讨论，结论在站内）。

字段说明：

| 字段 | 含义 |
|------|------|
| `messages` | 已产出的发言，**只会变长不会重排**。按"已读到的条数"增量渲染，已渲染的不要重复输出 |
| `expected` | 本场预计总条数（导师数 × 轮次）。**0 = 还没组好局**（导师未推荐出来），据此判断"还剩几句" |
| `status` | `pending` / `running` / `completed` / `failed`。**未到 completed 也可能有 messages**（一位导师说完就多一条） |
