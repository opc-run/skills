# GitHub精选开源项目排行和搜索 / opc-run-github-projects-radar

---

## 简介

一句话找开源项目，但**不只是 Star 数**。

这个 Skill 连接 [OPC.run 开源精选](https://opc.run/projects) 的每日 Star 快照与 AI 六维评估结果，回答别的工具答不了的问题：这个项目一个人能不能接得住、能不能做成一门生意、协议能不能商用。

**核心价值**

- **一个检索入口就够**：描述需求能找到，直接给关键词 / 项目名同样能命中（底层是向量 + 全文的混合召回）

- **增长榜单**：周榜 / 月榜按「增长综合分」排序 —— 绝对增量 + 相对增速 + 加速度的加权百分位，小体量高增速项目也能上榜

- **能赚钱吗**：AI 六维评估给出一个商业价值总分、等级与置信度；六个维度（痛点强度 / 目标客户 / 二次开发可行性 / 个人可独立完成度 / 变现空间 / 协议友好度）的**逐项得分与依据在站内详情页**

- **下一步怎么做**：最小产品切入方向、目标客户与变现模式，也在站内详情页 —— Skill 只负责把你送过去

- **选品辅助**：多项目横向对比（想找同类时，用同一检索入口以项目名 / 技术栈再搜一轮，由 Agent 自行比对）

- **零依赖 + 本地缓存**：纯 Python 标准库，结果本地缓存，重复提问不烧额度

**适用对象**

- 🧑‍💻 **独立开发者 / 超级个体** — 找能一个人做成产品的开源底座

- 🔎 **技术选型负责人** — 横向对比多个候选，看二次开发成本与协议风险

- 📈 **关注趋势的人** — 每周 / 每月看哪些方向在真涨

- 🧭 **找灵感的人** — 描述想解决的问题，直接拿到候选清单

## 功能特性

### 检索

- **语义检索（唯一的检索入口）**：底层是**向量 + 全文的混合召回**，所以既支持"帮一个人搞定客户工单的系统"这类自然语言描述，也支持直接输入关键词、仓库名或技术词（`langgraph`、`MCP`、`RAG`）

- **不用区分两种用法**：关键词与整句话走同一个入口、同一份结果口径；可用 `--tag` 限定分类

### 榜单

- **周增长榜**：近 7 天 Star 增速 Top N

- **月增长榜**：近 30 天 Star 增速 Top N

- **商业价值榜**：AI 六维评分 Top N

- 全部支持按分类过滤，数据每日重算

### 项目详情（摘要）与选型对比

- **详情也是摘要**：Star / Fork / Issue、双周期增长、协议与风险等级、商业价值评分 + 等级 + 评估置信度

- **六维逐项得分与依据、最小产品切入方向、变现模式、Star 增长曲线只在站内详情页** —— Skill 与开放接口都不返回这些字段；每条摘要末尾都带站内详情页链接，点过去就能看全文

- **找同类 / 平替**：没有单独的相似接口 —— 用关键词或需求再检索一轮，由 Agent 对比返回的字段自行判断

- **横向对比**：一张表比完多个候选（客观指标 + 商业总分）；逐项评估的对比需进各自的站内详情页

  {"env":{"OPCRUN_API_KEY":"sk_xxxx..."}}       # Agent 配置文件的 env 段

- 禁止在代码、提示词、日志或输出文件中硬编码 / 明文暴露密钥

## 使用指南

直接用自然语言说需求即可，也可以只给关键词或项目名 —— 无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| --- | --- | --- |
| 找方案 | "有没有一个人也能运维起来的工单系统" | 语义检索，返回候选与推荐理由 |
| 找具体项目 | "langgraph"、"有没有 MCP 相关的" | 关键词与整句话同一入口，都能命中 |
| 看趋势 | "AI 这周有什么项目在涨" | 按分类拉周增长榜 |
| 看月榜 | "本月增长最快的开源项目" | 全站月增长榜 |
| 找能变现的 | "哪些开源项目适合做成付费服务" | 商业价值榜 |
| 判断项目 | "xxx/yyy 能商业化吗" | 商业价值评分 + 置信度摘要，并引导进站内详情页看六维依据与切入方向 |
| 找平替 | "有没有类似 xxx/yyy 的" | 以该项目名 / 技术栈再检索，Agent 自行对比筛选 |
| 二选一 | "A 和 B 该选哪个做二次开发" | 横向对比表 |

## 使用场景

| 场景 | 角色 | 示例问法 | 收益 |
